Oto bezpośredni link do projektu: https://projekt-kz.surge.sh

Aplikacja typu Dashboard śledząca kursy kryptowalut,posaidająca stronę kontaktową(testową),oferowane usługi a także formularz zawierający możliwość dopracowania niedociągnięć
Aplikacja posiada:
- Pobieranie aktualnych kursów kryptowalut
- Obsługę wyboru walut
- Automatyczne odświeżanie danych
- Wyłapywanie błędów
- Funkcję AbortController przeciw Race Conditions

  Formularz:
- Zarzadząnie poziomem zaawansowania kandydata
- Uwagi rekrutera co do kodu


  Będę serdecznie wdzięczny za uzupełnienie Formularza w momencie obejrzenia projektu,gdyż uwagi będą dla mnie niezwykle cenne w ramach dalszego doskonalenia mojej wiedzy
